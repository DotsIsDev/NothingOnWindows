# Headphone (a) product photo

The multi-device build also embeds a distinct official photo for each of the 11 Nothing audio profiles under `Assets/Devices/<model-code>.png`. Exact CDN sources are listed in `Assets/Devices/sources.json`. These are model illustrations; colors are not automatically matched to Bluetooth serial numbers. Each image is displayed at its original proportions and served by Nothing's CDN as PNG, without retouching or background removal. See `DEVICE_SUPPORT.md` for the model-code mapping.
